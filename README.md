# Tableau- SAP Sales Dashboard
Tableau dashboard analyzing SAP sales data (using avg. pricing) — built to expand on Tableau skills I picked up in my ITM 220 (Management Information Systems) class

## What the project does
This is a Tableau dashboard that analyzes SAP sales data. It includes:
- A bar chart comparing average price vs. quantity sold, broken down by product type (Nut, Original, Strawberry, Blueberry Muesli) and region (NO, SO, WE)
- A pie chart showing total sales broken down by sales organization, with an interactive filter to narrow results by round (1–6)

## Why the project is useful
I first learned Tableau in my ITM 220 class and wanted to keep practicing outside of coursework. This project helped me get more comfortable with calculated fields, color encoding, filters, and combining multiple visuals into one clean dashboard using a real, messier dataset.

## Skills Used

- **Tableau** – built the full dashboard from raw data to finished visuals
- **Calculated fields** – created derived metrics (e.g. Avg Price) rather than using raw columns only
- **Data visualization** – bar chart and pie chart design, chosen to fit the data being shown
- **Color encoding** – used a quantity gradient on the bar chart and distinct colors per sales org on the pie chart
- **Filters / interactivity** – added a checkbox filter (Round 1–6) so viewers can narrow the data themselves
- **Categorical segmentation** – grouped data by region and product type to make comparisons easier to read
- **Dashboard design** – combined multiple charts into one cohesive, readable layout with titles and legends

## How to get started
1. Open the `.twbx` file in Tableau (Desktop or Public — both are free to download from tableau.com)
2. Use the "Round" filter on the right to narrow the sales organization data
3. Hover over any bar or pie slice for more detail
